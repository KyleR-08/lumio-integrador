# Lumio - Galería Cloud Segura

Proyecto Integrador, Avance 2. Programación Web, UIDE.

Integrantes: Kyle Reinoso, Ariel Esparza y Alejandro Zambrano.

Es el diseño de Lumio hecho solo con HTML y CSS, sin backend ni base de datos.

## Páginas

- index.html: login
- galeria.html: galería
- detalle.html: detalle de imagen
- registro.html: registro de imagen
- usuarios.html: gestión de usuarios
- perfil.html: perfil
- guardadas.html: imágenes guardadas

## Cómo abrirlo

Descargar la carpeta y abrir index.html en el navegador.

## Notas

- Todo el estilo está en style.css (Flexbox, Grid, :hover, :focus y @media para celular, tablet y escritorio).
- app.js es muy corto: solo oculta el enlace de Usuarios si la variable ES_ADMIN vale 0.
